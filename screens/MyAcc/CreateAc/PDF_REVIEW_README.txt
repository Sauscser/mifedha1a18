# To preview PDFs in React Native, use react-native-pdf. For images, use the built-in Image component.
# Installation (user must run):
# npm install react-native-pdf react-native-webview
# For iOS: npx pod-install
# Usage: <Pdf source={{ uri: pdfUri }} ... />
# For Android, ensure permissions are set.
# If PDF preview fails, provide a button to open in external viewer.
# This note is for developer reference only.
